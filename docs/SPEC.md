# Gilded Rose 요구사항 명세

Gilded Rose는 Allison이 운영하는 작은 여관입니다. 이 여관에서는 최고급 상품만을 사고 팝니다.
하지만 상품은 판매 기한이 지날수록 품질이 점점 떨어집니다.
이런 상황에 맞게 자동으로 재고 정보를 갱신해 주는 시스템이 있습니다.

---

## 필드 설명

| 필드 | 설명 |
|------|------|
| `SellIn` | 판매까지 남은 일수 (판매 가능 기한) |
| `Quality` | 아이템의 가치 |

---

## 기본 규칙

- 하루가 끝나면 시스템은 모든 아이템의 `SellIn`과 `Quality` 값을 갱신합니다.
- 각 아이템은 하루가 지날 때마다 `Quality`가 변동되며, 변경 규칙은 상품별로 다릅니다.
- 상품은 총 네 가지로 분류되며, 추가 확장이 가능합니다.

### 공통 제약

- 판매 기한이 지나면 `Quality`는 두 배 빠르게 떨어집니다.
- `Quality`는 절대 **0 미만**이 될 수 없습니다.
- `Quality`는 절대 **50 초과**가 될 수 없습니다.

---

## 아이템별 세부 규칙

### 일반 아이템

- 하루에 `Quality` 1 감소
- `SellIn`이 0 이하가 되면 `Quality` 2씩 감소

---

### Aged Brie

- 하루에 `Quality` 1 증가
- `SellIn`이 0 이하가 되면 `Quality` 2씩 증가

---

### Sulfuras

- 전설의 아이템으로, `SellIn`과 `Quality` 모두 변하지 않습니다.

---

### Backstage passes

콘서트가 다가올수록 `Quality`가 증가하며, 콘서트 종료 후에는 가치가 없어집니다.

| 조건 | Quality 변화 |
|------|-------------|
| `SellIn > 10` | +1 |
| `5 < SellIn <= 10` | +2 |
| `0 < SellIn <= 5` | +3 |
| `SellIn <= 0` (콘서트 종료) | 0으로 초기화 |
